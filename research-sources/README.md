# research-sources — ไฟล์ต้นฉบับสำหรับใช้ทำงาน ไม่ได้เผยแพร่บนเว็บ

โฟลเดอร์นี้อยู่**นอก `public/`** โดยตั้งใจ Next.js และ Vercel จึงไม่เสิร์ฟไฟล์ในนี้
ที่ URL ใดๆ ของเว็บ — เก็บไว้ให้ Claude หรือเครื่องมือ AI ที่ทำงานในคลังนี้อ่าน
ตอนเขียนบทสรุปหรือทำคอนเทนต์จากงานวิจัย

## กติกาข้อเดียวที่ห้ามผิด

**ใส่ได้เฉพาะไฟล์ที่สัญญาอนุญาตเป็น Creative Commons เท่านั้น**

เพราะ **คลัง GitHub นี้เป็นสาธารณะ** ใครก็เปิดดูและดาวน์โหลดได้ การเอาไฟล์ที่
สำนักพิมพ์ถือลิขสิทธิ์มาวางในนี้จึงเท่ากับเผยแพร่ซ้ำโดยไม่ได้รับอนุญาต ไม่ต่างจาก
การเอาขึ้นหน้าเว็บ — การที่ไม่มีลิงก์จากหน้าไหนไม่ได้ทำให้มันเป็นไฟล์ส่วนตัว

ตรวจสัญญาอนุญาตก่อนเสมอ วิธีตรวจต่างกันตามว่างานนั้นมี DOI หรือไม่

**ถ้ามี DOI** — เปิด https://api.unpaywall.org/v2/<DOI>?email=<อีเมล> แล้วดู
`best_oa_location.license` ต้องขึ้นต้นด้วย `cc-` เท่านั้น

**ถ้าไม่มี DOI** (วารสารไทยใน ThaiJO ส่วนใหญ่เป็นแบบนี้) Unpaywall ใช้ไม่ได้เลย
ต้องไปดูหน้าเว็บเอง โดยหา**ลิงก์ไป `creativecommons.org/licenses/...`** ซึ่งเป็น
หลักฐานที่หนักแน่นที่สุด ดูสองที่คือหน้าบทความและหน้านโยบายของวารสาร
(`/about`, `/about/submissions`, `/information/authors`) · ไม่เจอลิงก์ที่ไหนเลย
ให้ถือว่า**ไม่ใช่ CC** และห้ามเอาไฟล์ลงคลังนี้ · meta `DC.Rights` ที่ขึ้นว่า
`Copyright (c)` เฉยๆ ไม่ใช่สัญญาอนุญาต

ผลตรวจรอบ 1 ก.ย. 2569: `jcomm` (วารสารนิเทศศาสตร์ จุฬาฯ) เป็น CC BY-NC-ND 4.0 ·
`jprad` (การประชาสัมพันธ์และการโฆษณา) และ `jcmn` (นิเทศศาสตร์ฯ นิด้า) **ไม่มี CC**

**"เปิดอ่านฟรี" ไม่เท่ากับ "เผยแพร่ซ้ำได้"** วารสารจำนวนมากเปิดให้อ่านบนเว็บตัวเอง
โดยไม่ได้ให้สิทธิ์ใครเอาไปวางที่อื่น (Unpaywall เรียกสถานะนี้ว่า bronze) —
ThaiJO ที่ให้ดาวน์โหลด PDF ได้ฟรีทุกคนก็อยู่ในกลุ่มนี้ ดาวน์โหลดมาอ่านได้ แต่เอาลง
คลังสาธารณะไม่ได้

## ถ้าต้องให้ AI อ่านบทความที่ปิดหรือไม่ใช่ CC

อย่าเอาลงคลังนี้ ให้เก็บในที่ส่วนตัวแทน เช่น Google Drive ของศูนย์ฯ แล้วให้ AI
อ่านจากที่นั่นเป็นครั้งคราว — การอ่านเพื่อทำความเข้าใจและเขียนสรุปด้วยคำของเราเอง
ทำได้กับทุกบทความไม่ว่าลิขสิทธิ์เป็นของใคร สิ่งที่ทำไม่ได้คือการ**เผยแพร่ตัวไฟล์ซ้ำ**

## รายการปัจจุบัน

ไฟล์ใน `papers/` ทั้งหมดตรงกับ field `localCopy` ใน `src/data/paperSummaries.ts`
และทุกไฟล์มีสัญญาอนุญาต CC กำกับไว้ใน field `license` ของรายการนั้น

รายการที่**ไม่มี** `license` คือบทความที่วารสารสงวนลิขสิทธิ์ไว้ บทสรุปบนเว็บเขียน
จากการอ่านตัวบทความจริงเช่นกัน แต่ตัวไฟล์อยู่นอกคลังนี้ตามกติกาข้างต้น
