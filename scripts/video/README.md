# scripts/video — ตัวประกอบวิดีโอเล่าสาระหลักของบทความ

วิดีโอสั้น (1:40–1:50) หนึ่งเรื่องต่อบทความ × ไทย/อังกฤษ สำหรับฝังบนหน้า `/research/[slug]`
นำร่องแล้ว 3 เรื่อง (ไข้เลือดออก · นิทรรศการช้าง · อนิเมะ) กติกาที่ตกลงกับผู้ใช้อยู่ใน `CLAUDE.md` หัวข้อ
"วิดีโอเล่าสาระหลักของบทความ" — **อ่านก่อนทำเรื่องใหม่** โดยเฉพาะข้อ "ศูนย์ฯ เป็นผู้เล่า ไม่ใช่ผู้ทำ"

โค้ดในโฟลเดอร์นี้คือสำเนาอ้างอิงของตัวประกอบที่รันจริงในเซสชัน Claude (scratchpad หายเมื่อเซสชันจบ)
**ไฟล์สื่อไม่อยู่ในคลัง** เพราะคลังเป็นสาธารณะและมีเสียงโคลนของผู้ใช้ — ผู้ใช้เก็บ zip ไว้เอง (ส่งให้ 4 ก.ย. 2569)

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `storyboard.py` | **แหล่งความจริงเดียว** ของทุกเรื่อง: ฉาก 8 ฉาก/เรื่อง (hook · method · finding×3 · conclusion/lesson · caveat · closing) · บทพากย์ไทย/อังกฤษทีละย่อหน้า · ป้ายและข้อความบนจอ · แนวคิดภาพ + prompt เจนภาพ · คู่สีต่อเรื่อง · รันแล้วได้ `storyboard.json` (ให้ตัวประกอบ) `storyboard.html` (ให้ผู้ใช้ตรวจ) `scripts-pilot-v2.md` |
| `build_v2.py` | **เรนเดอร์เฟรม**: วางภาพ paper-craft ฝั่งขวา (ละลายขอบเข้าพื้นครีม) ข้อความ Kanit ฝั่งซ้าย · `wrap()`/`fit_text()` ตัดบรรทัดไทยตามวรรคก่อน (ดูกติกา) · `render_closing(lang, credit)` การ์ดปิดพร้อมชื่อผู้เขียนทุกคน · `make_clip()` ซูมเบาๆ ด้วย zoompan · `--frames <key> <lang> <dir>` เรนเดอร์เฉพาะภาพนิ่งไว้ตรวจ |
| `build_v3.py` | **ประกอบคลิป** จากเสียงพากย์ทีละย่อหน้า: ตัดความเงียบหัวท้าย → วางบนไทม์ไลน์พร้อมช่องหายใจ → xfade ฉากตามเสียง → จิงเกิลเปิด/ปิด + เพลงพื้นหลังกดลงเมื่อพูด (sidechain) + SFX กระดาษตรงรอยต่อ → มาสเตอร์ (EQ · compressor · loudnorm −16 LUFS) · เขียน `<out>.timeline.json` |
| `credits.py` | ดึงชื่อผู้เขียนทุกคน + วารสาร + ปี จาก `citation.authors` ใน `src/data/publications.ts` ผ่าน `doi`/`indexUrl` ของ `paperSummaries.ts` (อ่านไฟล์เป็นข้อความเหมือน `check-content.ts`) |
| `check_wrap2.py` | พิมพ์ทุกบรรทัดของทุกฉากทั้งสองภาษาพร้อมขนาดฟอนต์ ฟ้อง `INTRA` ถ้ามีการตัดภายในวรรค และเรนเดอร์ contact sheet ต่อเรื่องต่อภาษาไว้ตรวจด้วยตา — **รันก่อนประกอบทุกครั้ง** |

## สิ่งที่ต้องมีในโฟลเดอร์ทำงาน (ไม่อยู่ในคลัง)

```
fonts/Kanit-Regular.ttf  fonts/Kanit-Medium.ttf     # จาก Google Fonts (น้ำหนัก 400/500 ตาม BRAND.md)
images-v2/<key>-NN.png                              # ภาพฉากที่เจนแล้ว 1376×768 (ฉาก hook ใช้ภาพประจำบทความจาก public/)
audio-v3/<key>-<th|en>/p1.mp3 … p8.mp3              # เสียงพากย์ทีละย่อหน้า ตามลำดับฉากใน storyboard.json
assets/jingle-A.mp3  assets/bed-A.mp3               # จิงเกิล 8 วิ · เพลงพื้นหลัง (loop) — เจนด้วย eleven_music_v2
assets/sfx-2-slide.mp3  assets/sfx-3-setdown.mp3    # เสียงกระดาษ — eleven_text_to_sound_v2
```

ต้องมี Python 3 + `pip install pillow imageio-ffmpeg` และ Node 22 (ใช้ `Intl.Segmenter('th')` ตัดคำไทย วิธีเดียวกับ `src/lib/text.ts`)

## ขั้นตอนทำเรื่องใหม่

1. เพิ่มเรื่องใน `CLIPS` ของ `storyboard.py` (บท 8 ย่อหน้า × 2 ภาษา · ข้อความบนจอ**เว้นวรรคตามหน่วยความหมาย** · แนวคิดภาพนับวัตถุไม่เกินสี่ชิ้น) แล้ว `python3 storyboard.py` → ส่ง `storyboard.html` ให้ผู้ใช้อนุมัติ
2. เจนภาพ 7 ใบ/เรื่อง (gemini-3-pro-image ผ่าน ElevenLabs $0.20/ใบ) → `images-v2/` · ตรวจว่าตรงแนวคิด ถ้าไม่ตรงเขียน alt ตามที่เห็นจริงและถามผู้ใช้
3. `python3 check_wrap2.py` — ต้องได้ `INTRA breaks: 0` แล้วดู contact sheet
4. อัดเสียง**ทีละย่อหน้า** ด้วย `eleven_v3` เสียงโคลนของผู้ใช้ (ไทย Smith Boon · อังกฤษ Smith Boonbr) ประเมินราคาและขออนุมัติก่อนทุกรอบ → ดาวน์โหลดเป็น `audio-v3/<key>-<lang>/pN.mp3`
5. `python3 build_v3.py <key> th out/<key>-th.mp4` และ `en` → วัด integrated loudness ทุกคลิป (ควรได้ −16 ± 0.3 LUFS) แล้วดึงเฟรมสุ่มตรวจก่อนส่ง

ค่าที่ปรับได้โดยไม่ต้องอัดเสียงใหม่อยู่หัวไฟล์ `build_v3.py` (ช่องหายใจ · ระดับจิงเกิล/เพลง/SFX · EQ)
