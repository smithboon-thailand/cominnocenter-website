# scripts/video — ตัวประกอบวิดีโอเล่าสาระหลักของบทความ

วิดีโอสั้น (1:40–1:50) หนึ่งเรื่องต่อบทความ × ไทย/อังกฤษ สำหรับฝังบนหน้า `/research/[slug]`
ทำแล้ว 18 เรื่อง — นำร่อง 3 (ไข้เลือดออก · นิทรรศการช้าง · อนิเมะ) + ชุดที่ 2 อีก 5 (อ้างอิงจากแชตบอต · วิดีโอ 360 · ภาพไทยหลังปลดล็อกกัญชา · รีวิวลบกับโฆษณาเปรียบเทียบ · ออกแบบร่วมกับแรงงานข้ามชาติ) + ชุดที่ 3 อีก 5 (ความน่าเชื่อถือของรัฐช่วงโควิด · เจนซีกับสินค้าไม่ทดลองกับสัตว์ · เทคโนสเตรสนิสิตปีหนึ่ง · ห้องไลฟ์ JOOX Rooms · วีทูปเบอร์กับสตรีมเมอร์) + ชุดที่ 4 อีก 5 (สื่อจีนกับภาพไทยหลังปลดล็อกกัญชา · ผู้สนับสนุนคอร์สที่แฟนคลับแปลซับ · จุดยืนของแบรนด์กับการอยากซื้อ · สื่อโต้ตอบในห้องเรียนออนไลน์ · เจ้าหน้าที่สาธารณสุขกับการแลกเปลี่ยนความรู้) กติกาที่ตกลงกับผู้ใช้อยู่ใน `CLAUDE.md` หัวข้อ
"วิดีโอเล่าสาระหลักของบทความ" — **อ่านก่อนทำเรื่องใหม่** โดยเฉพาะข้อ "ศูนย์ฯ เป็นผู้เล่า ไม่ใช่ผู้ทำ"

โค้ดในโฟลเดอร์นี้คือสำเนาอ้างอิงของตัวประกอบที่รันจริงในเซสชัน Claude (scratchpad หายเมื่อเซสชันจบ)
