# ComInnoCenter Website

**Center of Excellence in Communication Innovation for the Development of Quality of Life and Sustainability**  
Faculty of Communication Arts, Chulalongkorn University

## Tech Stack
- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- Ready for Vercel deployment

## Design System
Based on the design work in [cominnocenter-premium-redesign](https://github.com/smithboon-thailand/cominnocenter-premium-redesign)

**Brand Colors**:
- CU Pink: `#DE5C8E`
- Faculty Blue: `#002D73`
- Neutral Off-white: `#F8F5F2`

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Deployment on Vercel
1. Go to [vercel.com](https://vercel.com)
2. Import this GitHub repository
3. Deploy
4. Later point `cominnocenter.com` DNS to Vercel
