# นโยบายปัจจุบัน: เปิดให้ทุกบอตเก็บข้อมูลได้ทั้งเว็บ ทั้งบอตค้นหาและบอต AI
# เว็บนี้เป็นเว็บสาธารณะของหน่วยงานวิชาการ ไม่มีส่วนที่ต้องปิด
#
# ⚠️ ข้อควรระวังสำคัญเวลาจะแก้ไฟล์นี้
# robots.txt **ไม่มีการสืบทอดกฎ** บอตจะอ่านเฉพาะกลุ่มที่ตรงกับชื่อตัวเองมาก
# ที่สุดกลุ่มเดียว แล้วเมินกลุ่ม * ทั้งหมด ดังนั้นถ้าวันหนึ่งเพิ่ม Disallow
# ให้ * **ต้องไปเพิ่มในทุกกลุ่มด้านล่างด้วย** ไม่งั้นบอต AI จะยังเข้าส่วนที่
# ตั้งใจปิดได้อยู่

User-agent: *
Allow: /

# — บอต AI ที่ "ค้นเว็บสดตอนผู้ใช้ถาม" แล้วอ้างอิงกลับมาที่เว็บเรา —
# กลุ่มนี้คือช่องทางที่ผลงานศูนย์ฯ จะไปโผล่ในคำตอบของ ChatGPT / Claude /

# ถ้าวันหนึ่งเปลี่ยนใจ ให้แก้ Allow เป็น Disallow เฉพาะกลุ่มในส่วนนี้
